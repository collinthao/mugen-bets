This is my edited version of Mario made originally by ShinRyoga and NeoHank.

It's mostly a sprites update, so don't expect a big change of the gameplay.

---WHAT BASICALLY YOU NEED TO KNOW---

-Mario aerial combos are more deadlier than Luigi's;
but his land combos make less damage.

-New sounds.

-A new time over animation.

-A new intro against Luigi.

-"Grow intro" erased and changed with a totally different one.

-Dusts and flames added.

-MvC backgrounds added.

-All the sprites are now edited, so you can edit the palettes making the hat with a different color than the shirt. 

-Super Flame move erased and  replaced with the Mario's Finale. This move can be performed in air.

-All the level 3 supers can now be performed by simply pressing D, DF, F, a/b/c.

-Now you can be hurt during the Hammer and the Mario Finale.

-The Mario Tornado EX is a single hit move if performed in air.

-The Air Glide EX is now performed by pressing "-> + b + c".

-New Taunt! If you press start + down, you'll activate the "Favorite Crowd" from the SSB series. (DELETED BECAUSE OF A GLITCH)

-Mario is now able to dodge! Press down + 2 kicks.



---3 NEW SPECIAL MOVES!--- 
1) Reflector Cape (D, DB, B, a): Move able to reflect projectiles. Can be done in air. Does no damage.
2) Super Headstomp (D, DB, B, b): Mario will jump on the enemy's head, the position doesn't matter. 
However, if the opponent is in a certain state, Mario might miss him. If the move hits, it can be canceled into any other aerial special move.
This move can be blocked and is easily punished, so use it wisely! (Cannot be done in air)
3) Hammer Swing (D, DB, B, c): A simple move. If it hits, it can be canceled into the EX Tornado or Ex Coin Punch.
If done in air, it will slam the opponent on the ground.



---NEW PALETTES!---
-All his Brawl costumes
-Ice Mario (New Super Mario Bros. Wii)
-Flying Mario (Super Mario Galaxy)
-Hyper (a tribute to Alvin's amazing  Super Mario Bros. Z series!)
