;******************************************************************************
;適当な技解説？
;******************************************************************************
;●必殺技
;・黄飛鴻
;  自分の名前を設置する。アピールしたい時及び相手を固める時におススメ。
;  ダメージ低い上に通常食らい中には基本当たらない弱技なのだが…。
;・飛行傘 
;  傘を3つ発生やして射出する技。ヒット後は夢へ向かって旅立っていく。
;  フルヒットしないとダメージが低いが一番下の傘が下段判定な為それなりに役立つ。
;  おまけ要素としてまれに変なものが発射される。ダメージも大きくなる。
;・佛山無影脚
; 「じょうろじょうろ」言いながら妖怪のような脚捌きで迫り行く技。
;  始動がガード可能になった。
;・佛山無影手
;  つっぱり大相撲。
;  一定ヒット時に閃躱にキャンセル可能。強い(多分)
;・獅子功
;  おさげアタック。
;  強化なしの時は気絶狙い以外の価値がない4に技。他が優秀過ぎて…んもう。
;  人操作時でこのキャラを相手にする時はこの技を使う時を狙うと安定。("POWER"or"SP-POWER"表示中じゃない時)
;・上攻
;  ライジングタックル！
;  超優秀な対空技。画面端ならこれだけ連発の永久も可能。
;・必肘
; 「煮えきった！」と熱い言葉ともに炎のエルボードロップ。
;  地上版はヒット、ガードを問わずA級(永久)確定。このキャラの最強技？
;・連環旋風腿
;  わざわざ傘を差して脚をバタバタさせる投げ技。
;  ここぞという時は傘を差してオシャレな自分を演出しよう！
;・偽挑発
;  挑発詐欺の当身技。無敵もあり使い勝手はよく格好いい！(決まれば)
;  超必殺技の使用条件を満たすと亂拳が超級亂拳へとパワーアップ！
;●超必殺技
;・超級黄飛鴻
;  劣化ウロボロス。
;  しかし通常版と上手く組み合わせる事により相手ガードからのK.O.も狙える。
;・超級飛行傘
;  大きくなった傘を3連で放つッッッッ！！
;  ダウン追撃可能で下段判定なのでその部分を生かそう。
;  この技のみ衝撃波エフェクトに中段(こちらもダウン追撃可能)の攻撃判定が発生する。つまり…。
;・真・超級亂拳
;  始動がガード不能な乱舞技。ダメージも大きく格好いい！
;  始動すると成否に問わずゲージが減る。
;・絶・超級亂拳
;  ブロッキング詐欺の当身技。が、対プレイヤー操作では音でバレバレ(ガード音が出ない)
;  発生が早く終わりまで完全無敵だけど範囲が狭め。
;  だが失敗してもゲージが減らないという利点もある。
;  元キャラの横掃千軍はこの技でしか見れないぞ！！
;●特殊超必殺技
;・獅死奮刃
;  獅子舞みたいなのが後ろを駆け抜けるだけの技、「自分は」攻撃しない。
;  その力を確かみてみろ！！
;━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
;━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
;******************************************************************************
;キャラ性能
;******************************************************************************
;・人操作時はお手軽強キャラ(狂下位～狂中位程度)
;・AI時は凶中位～狂中位の範囲になる。
;・ガードは全てブロッキングになる。ブロッキングは閃躱でキャンセル可能。
;・通常弱攻撃は通常強攻撃にしかキャンセル出来ないので相手が特殊な仕様orタッグじゃない限り他には繋がらない。
;・通常強攻撃同士は基本繋がらない、ある事をすれば繋がるものもあるが繋がらないと思っていい。
;━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
;━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
;******************************************************************************
;コンボ例
;******************************************************************************
;・お手軽基本コンボ
;  必肘(地上版) × n(ヒットorガード)
;  相手空中時一定の高さ以上or画面端で　上攻 × n(ヒット時のみ)
;・お手軽即死コンボ
;  (佛山無影手→ヒットキャンセル閃躱) × 2以上(相手体力次第) → 力溜 → 超級亂拳
;・理論上出来るはず…なコンボ(空振りさせるタイミングが難しい)
;  立ち強キック(not近距離)ヒット→連環旋風腿空振り→立ち強キック(not近距離)ヒット→連環旋風腿空振り→…
;・他にも一杯コンボ(即死/A級/ハメ)がありますが割愛します。
